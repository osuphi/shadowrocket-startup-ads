# Shadowrocket Precision v3

这是一份以正常业务功能优先的公开分流配置，针对原先将大范围广告域名名单置于服务规则之前的做法进行结构调整。它不是“全部 App 实测无误拦”或“去除全部广告”的承诺。

## 导入和更新

远程配置地址：

https://raw.githubusercontent.com/osuphi/shadowrocket-startup-ads/main/routing/Shadowrocket-Precision.conf

在 Shadowrocket 配置页添加该远程配置，下载并“使用配置”，等待远程规则资源加载完成。保留旧配置，首页继续使用现有节点订阅；全局路由选择“配置”。这份文件不包含节点、订阅密码或证书。

首次测试保持节点与模块状态和之前正常时一致。确认直播、登录、支付等功能后，再逐个启用需要的去广告模块。模块可能有独立的误拦或解密兼容性问题，主配置的保护不能覆盖所有外部模块行为。

在 Shadowrocket“设置 → 配置”开启自动后台更新，间隔选 1 天，同时允许 iOS 后台 App 刷新。仓库每天北京时间约 09:23 先下载规则源的固定提交快照，经过生成、校验后发布；手机再按自身调度刷新。两个调度都不保证精确时刻。

文件包含公开的 update-url，因此整份框架和规则资源都可以远程刷新。手工编辑该远程配置可能在更新时被覆盖，长期自定义应使用单独副本。已有策略组保存的选择也可能覆盖默认值，请检查国内直播、国内通讯、国内支付、运营商服务、国内网站、Apple、Steam 下载为 DIRECT；海外服务跟随“选择节点”；“拦截广告”为 REJECT。

客户端的使用和自动更新路径依据 [LOWERTOP 社区手册](https://github.com/LOWERTOP/Shadowrocket/wiki)，不是开发商官方操作手册。

## 这次解决的结构问题

- 广告层不再直接加载旧的 AdvertisingLite 全量域名文件。改从 [HaGeZi Multi LIGHT](https://github.com/hagezi/dns-blocklists#light) 提取已列出的明确广告端点。除少量明确审核的广告域族外，输出使用精确 DOMAIN，不把单个主机扩大成整域及所有子域。
- 消息、接口、统计、故障上报、配置和推送的名称不因被上游收录就自动封禁。维护明确功能保护范围；国内通讯、支付、直播和 Apple 系统服务优先于广告名单。
- 新增国内直播、国内通讯、国内支付、运营商服务四个策略组。补齐斗鱼及 CDN、虎牙、微信、钉钉、支付宝、银联、移动、电信、联通分类；广电的 10099.com.cn 仅作域名直连，并不能关闭系统 VPN 或保证修复其闪退。
- OpenAI 仅使用明确的专属域名和已审核端点，不按共享 ASN、关键词或所有 Sentry/Auth0/Stripe 流量归类。共享服务正常通行。
- Google、YouTube、GitHub、Apple、Microsoft、Bing/Copilot、OneDrive、Steam 等保留独立分组。业务规则标准化为域名规则；只有国内基线保留国内 CIDR，避免业务类共享 IP 覆盖无关 App。OneDrive 的 1drv.ms 使用明确后缀，不再依赖包含“1drv”的任意域名关键词。
- Apple、China 的主文件和域名伴随文件在生成时配对合并。根据实际优先级删除较后位置的重复精确匹配。不同范围规则的包含关系仍由顺序决定，不声称不存在全部语义重叠。
- DNS 沿用 system；不擅自开启新的 DNS 劫持、全局回落直连或 HTTPS 解密。MITM 默认关闭，不携带证书。现有首页节点订阅继续使用。

## 广告效果与兼容性

初次构建从 HaGeZi LIGHT 的 79,665 个域名提取 1,281 条保守广告规则。条目数量不代表实际拦截率或兼容性保证；后续数量会随上游变化。

正常直播和业务功能优先，斗鱼及部分应用的开屏广告可能保留。独立开屏模块处理具体路径，涉及 HTTPS 解密时有自己的兼容性边界；这份配置不会自动启用它，也未为斗鱼新增未经设备验证的重写。

中国广电 App 在任何规则下开启代理均闪退，需要作为 VPN 环境兼容性问题单独验证。仅凭这一现象不能认定 App 主动检测 VPN，也不能保证加直连即可解决。

## 自动更新保护与验证

`sync_routing.py` 从固定公开地址获取 blackmatrix7 与 HaGeZi 源，每次先固定各仓库提交，再下载对应文件，避免同一次构建混用该仓库的不同版本。不执行上游脚本。

发布前检查语法、分组引用及环路、最终规则、规则次序、远程引用、域名边界、精确重复匹配和保护样例。下载、解析、回归检查失败或某类别有效条目比上次下降超过一半，就不提交新文件，保留仓库里上一版资源。更新按一次 Git 提交发布；手机对多个文件的获取时机不保证完全同步。

首次本地结果：16 个生成器测试通过；108 个分流样例通过；23 个功能域名保护和 23 个模拟源更新保护场景通过；展开后没有重复的精确匹配条件。状态、各文件摘要和固定输入提交见 `Status.json`。

这些是格式与匹配模拟检查，不是 iPhone 原生导入、真实 DNS/GeoIP、TLS、直播或所有应用版本的实测。任意静态名单都无法保证所有 App 永远不出问题。

python -m unittest discover -s routing -p test_routing.py -v
python routing/sync_routing.py --repository osuphi/shadowrocket-startup-ads
